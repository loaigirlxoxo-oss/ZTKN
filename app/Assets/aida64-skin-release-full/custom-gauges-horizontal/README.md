# AIDA64 Custom Gauge State Images

These are real AIDA64 custom gauge source images.

Each folder contains 16 transparent PNG states:

- `state-01.png` = lowest / empty
- `state-16.png` = highest / full

In AIDA64 SensorPanel Manager:

1. Add a custom gauge.
2. Select the 16 files from one folder as the gauge states.
3. Set the sensor source and min/max range.
4. Resize the gauge item to the desired displayed size.

Do not use these as single static images if you expect dynamic behavior.

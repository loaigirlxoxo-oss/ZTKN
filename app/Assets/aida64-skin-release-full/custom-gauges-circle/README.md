# AIDA64 Round Custom Gauge State Images

Each folder contains 16 transparent PNG states for an AIDA64 Custom Gauge.

- `state-01.png` = lowest
- `state-16.png` = highest

Recommended:

- CPU: `gradient-cpu-pink-yellow-lime` or `gradient-heat`
- GPU: `gradient-gpu-cyan-purple-pink` or `gradient-heat`
- If colored arcs feel too busy: `neutral-track-heat-marker`

Use AIDA64 text items separately for numeric values.
